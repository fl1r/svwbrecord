# ユーザー体験 (UX) 改善計画書

本ドキュメントは、戦績記録ツールにおける「ユーザー視点での操作性向上」と、今後の改善ロードマップを記述したものです。

## 1. 入力フローの分析（現状 vs 理想）

### 現状のフロー（5〜6ステップ）
1. 通知・ボタンをタップ
2. 自分のデッキを選択
3. 相手のデッキを選択
4. 先攻・後攻を選択
5. 勝敗を選択（← **今回、色付けで改善**）
6. 「記録」ボタンをタップ

### 理想のフロー（3ステップ以下）
1. 浮遊ボタンをタップ
2. 相手のデッキと勝敗を一画面で同時に選択（自分のデッキは前回と同じものを自動設定）
3. 記録完了（自動で閉じる）

## 2. 実施済みの改善点

- **勝敗ボタンの視覚的強調**:
    - 「勝ち」ボタンを **青色（#2196F3）** に変更。
    - 「負け」ボタンを **赤色（#F44336）** に変更。
    - 太字と色付きボタンにより、一目でどちらが何であるかを判断可能に。

## 3. 今後の推奨改善項目

### UI・インタラクション
- **「自分のデッキ」を記憶する**:
    - 前回の記録内容を `SharedPreferences` に保持。
    - 次回起動時に、前回と同じデッキが最初から選択されている状態にする。
- **ダークテーマ / 半透明背景**:
    - ゲーム（シャドウバースWB）の世界観に合わせ、黒基調の半透明なデザインに変更。
- **配置のカスタマイズ**:
    - ポップアップ自体をドラッグして、ゲーム画面の邪魔にならない位置へ移動できる機能。

### 堅牢性・機能性
- **記録成功の通知**:
    - Google Sheets への書き込みが完了したことを、画面上のアイコンやサウンドでフィードバック。
- **簡易取り消し機能**:
    - 直前の記録を「なかったことにする（最後に1行削除）」ボタンの追加。

## 4. 目指すべきユーザー体験

**「ゲームのプレイリズムを崩さないこと」**
記録のための操作は、対戦終了から次のマッチングを開始するまでのわずか数秒の間に行われる必要があります。
そのため、**「最小限の視線移動」**と**「最小限の指の動き」**で完結するデザインを追求します。
