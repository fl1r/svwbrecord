通知・フローティングボタン 2モード記録システムのアーキテクチャ

システム概要

本アプリは、Androidの UsageStatsManager を利用して「シャドウバースWB」の起動状態をバックグラウンドで監視し、 ゲーム中にシームレスに戦績（勝敗・デッキ等）をGoogleスプレッドシートへ記録するためのツールです。

提供される2つの記録モード

1. 通知モード (Notification)

仕組み: ゲームを検知すると「戦績を記録」という通知を表示します。

  • 通知エリアを介して操作
  • ゲーム画面を一切邪魔しない
  • 通知タップでオーバーレイ起動

2. ボタンモード (Floating Button)

仕組み: ゲーム画面の最前面に常に小さな半透明ボタンを表示します。

  • ワンタップで入力画面を表示
  • ドラッグで移動可能
  • 入力を開始すると自動的に隠れる

主要クラス構成

クラス名 役割 詳細
MainActivity 設定画面 記録モードの選択、Googleサインイン、監視の開始/停止を管理。
GameWatchService 監視コア 2秒おきにフォアグラウンドアプリを確認。ゲーム開始を検知してモード別のUIを起動。
FloatingButtonService 浮遊ボタン WindowManager を使用してオーバーレイ層にボタンを描画。タップで記録画面へ。
OverlayService 入力UI 全画面（または部分的な）透明オーバーレイで戦績入力画面を提供。Google Sheets APIを呼び出す。

バッテリー最適化 (Battery Optimization)

バックグラウンド監視によるバッテリー消費を抑えるため、以下の最適化を実装しています。

  • 画面オフ時の監視停止: BroadcastReceiver を使用して ACTION_SCREEN_OFF を検知し、CPU負荷の高いポーリングループを完全に停止します。
  • 画面オン時の自動再開: ACTION_SCREEN_ON 検知時にのみ監視を再開し、必要な時だけリソースを消費します。
  • インタラクティブ判定: PowerManager.isInteractive() を併用し、不必要なタイミングでの処理開始を二重に防止しています。

sequenceDiagram participant User as ユーザー participant App as Android System / Game participant GWS as GameWatchService participant FBS as FloatingButtonService participant OS as OverlayService participant GS as Google Sheets App->>GWS: ゲーム起動を検知 alt 通知モード GWS->>User: 記録用通知を表示 User->>GWS: 通知をタップ GWS->>OS: OverlayServiceを起動 else ボタンモード GWS->>FBS: FloatingButtonServiceを起動 FBS->>User: 画面上にボタン表示 User->>FBS: ボタンをタップ FBS->>OS: OverlayServiceを起動 end OS->>User: 入力フォーム表示 User->>OS: 勝敗・デッキを入力 OS->>GS: スプレッドシートへ書き込み OS->>OS: 自身を終了
